# Agent instructions

## Agent skills

### Design interviews

For `$grill-me`, `$grill-with-docs`, and `$grilling`, use the repository-local [Grill Me](.agents/skills/grill-me/SKILL.md), [Grill with Docs](.agents/skills/grill-with-docs/SKILL.md), and [Grilling](.agents/skills/grilling/SKILL.md) skills. Their UI names end in **(repo version)**. Follow their interview handoff and [workflow stage boundaries](docs/workflow.md#from-design-to-implementation).

### Spec implementation

For `/implement-spec`, use this repository's version in [.agents/skills/implement-spec/SKILL.md](.agents/skills/implement-spec/SKILL.md).

### Issue tracker

Track specifications and implementation issues in GitHub Issues. Before creating, reading, or updating work items, read [the tracker conventions](docs/agents/issue-tracker.md).

### Triage labels

Use the five configured triage roles when classifying issues. Read [the role mapping](docs/agents/triage-labels.md) before changing triage labels.

### Domain docs

This repository has one domain context. Before exploring domain behavior or proposing changes, read [the domain documentation rules](docs/agents/domain.md).
