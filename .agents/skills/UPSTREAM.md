# Vendored skills

These skills are copied from https://github.com/mattpocock/skills (MIT),
commit `5863806dd4e15c63174bee4e7515a4256792ecfa` (plugin v1.3.2), using the set listed in its `.claude-plugin/plugin.json`.

`.claude/skills` is a symlink to this folder, so Claude Code sees the same skills
that Codex and other Agent Skills harnesses read from `.agents/skills`.

To update: clone the upstream repo, then re-copy those skill folders over these and review the diff.
