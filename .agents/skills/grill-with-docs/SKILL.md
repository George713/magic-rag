# Grill with Docs (repo version)

Use the [repository-local grilling procedure](../grilling/SKILL.md) and the `domain-modeling` skill together. Follow [the repository's domain documentation rules](../../../docs/agents/domain.md) when recording resolved terminology, accepted behavior, or qualifying ADRs. Capture settled decisions as the interview progresses; keep unresolved proposals distinct from accepted behavior.

Documentation is part of this interview. Confirm shared understanding and let the user choose the next workflow stage before implementing the design or publishing specifications, tickets, or PRs.

Invoke as `$grill-with-docs` and select **Grill with Docs (repo version)** in the UI.
