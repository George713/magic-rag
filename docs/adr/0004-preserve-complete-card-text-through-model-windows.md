# Preserve complete card text through model windows

Keep each complete canonical card document and cover every token with model-budgeted windows: aggregate BGE document vectors by token-weighted normalized mean into one vector per card, and aggregate query/card cross-encoder windows by maximum logit. Rejecting long cards or truncating abilities would lose corpus coverage; storing every chunk vector would preserve more localized signals but add index size and card-level retrieval aggregation, while the selected mean can dilute specific abilities and maximum reranker scores can favor partial matches. Changing the embedding window/aggregation policy requires rebuilding corpus embeddings, whereas changing only reranking does not; overlength search queries are rejected explicitly, and the benchmark must assess these quality trade-offs.
